# native-asr v0.1.0

`v0.1.0` is the first release of `native-asr`: local, CPU-only speech
recognition with no model weights embedded in its containers.

It contains two supported workflows:

- a deterministic three-model ensemble for accurate, provenance-complete
  long-form transcription; and
- a low-latency Nemotron-to-Parakeet cascade for provisional and committed
  English streaming text.

First-time setup is available through `just setup-long-form` and
`just setup-streaming`; `just doctor PROFILE` checks whether a selected workflow
is ready. Live capture does not begin until both cascade models are loaded.

The release gate used two deterministic 100-utterance LibriSpeech fixtures,
played into the real live-capture path through uniquely named, graph-checked
PipeWire virtual nodes. Both runs passed all 13 acceptance gates:

| Fixture | Nemotron WER | Committed WER | Partial p95 | Correction max | Degraded | RTF |
|---|---:|---:|---:|---:|---:|---:|
| `test-clean` | 4.87% | 4.35% | 142 ms | 847 ms | 0 | 1.00076 |
| `test-other` | 7.65% | 6.17% | 138 ms | 1,002 ms | 0 | 1.00081 |

The supported deployment target is CPU-only x86-64 Linux. Live capture
requires PipeWire and streaming recognition is English-only. GPU execution,
diarization, LLM adjudication, transcript editing, and the planned Rust TUI are
not part of this release. See the [changelog](../../CHANGELOG.md) and
[reproducibility report](../reproducibility-report.md) for full results and
limitations.
